## Brand & Style

The design system establishes a high-performance, ultra-premium neo-banking experience engineered for digital-native capital managers and tech-forward consumers. The aesthetic fuses dark-mode minimalism, tactical hardware ergonomics, and cybernetic luminous accents. 

Every surface is treated with restraint: deep abyss-toned obsidian canvases host frosted glass slabs, hairline illuminated edge lighting, and high-frequency tactile triggers. The interface evokes unyielding cryptographic security, fluid mechanical precision, and electric immediacy. Interactions should feel instantaneous, weighted, and haptic—transforming mundane financial transfers and ledger scrutiny into a luxury cyber-instrument experience.

## Colors

The palette is anchored in high-contrast extremes: pitch-dark obsidian and deep slate bases paired with high-voltage neon emitters.

- **Primary (`#D4F933` / Electric Lime):** The core active state, primary action trigger, and accent driver. Used deliberately for affirmative states, balance focus points, interactive pins, and primary CTA vectors.
- **Secondary (`#00F0FF` / Cyber Cyan):** Utilized for analytical indicators, secondary telemetry badges, cryptographic tokens, and secondary status tracks.
- **Tertiary (`#FF3B69` / Pulse Crimson):** Reserved for outflow balances, debit warnings, security breaches, and destructive flows.
- **Neutral Palette:**
  - `Canvas Deep`: `#080A0F` (True dark obsidian viewport substrate)
  - `Surface Glass Base`: `rgba(18, 22, 34, 0.72)` (Primary structural card plates)
  - `Surface Elevated`: `#141824` (Tactile pads, keypad triggers, secondary chips)
  - `Hairline Border Highlight`: `rgba(212, 249, 51, 0.18)` (Luminous top-edge rim lighting)
  - `Subtle Border Base`: `rgba(255, 255, 255, 0.08)` (Structural boundary defining lines)
  - `Text Primary`: `#F8FAFC` (Pure optical legibility on dark layers)
  - `Text Muted`: `#64748B` (Metadata, timestamps, auxiliary labels)

## Typography

The type system blends mathematical precision with hyper-modern fintech energy:

- **Headlines (`Space Grotesk`):** Engineered geometric grotesque with sharp angularities. Brings an authoritative, tech-forward posture to balances, card values, and module headers. Numeric values render with monospaced character widths to eliminate layout jitter during live value counters.
- **Body (`Hanken Grotesk`):** High-clarity neutral sans-serif offering rapid scannability for user metadata, transaction details, settings descriptions, and contextual feedback.
- **Micro & Labels (`JetBrains Mono`):** Monospaced precision for technical metadata including account masks (`•••• 7541`), transaction hashes (`tx_65fb8589_01`), timestamps, and financial tickers.

## Layout & Spacing

The layout model is constructed on an 8pt atomic grid designed around high-density mobile ergonomics. 

- **Mobile Viewports (< 640px):** Single-column vertical flow with full-width ergonomic touch targets. Outer canvas margins default to `margin` (`1.25rem / 20px`), creating an intentional frame around primary floating glass cards. Grid gutters remain compact at `1rem`.
- **Tablet / Desktop Screens (≥ 640px):** Expands to a structured 12-column grid capped at a maximum width of 1120px to preserve tight dashboard utility without dead whitespace sprawl.
- **Component Stacking:** Vertical stacks prioritize tap targets (minimum 48px to 56px height for numeric keys and CTAs) with strict internal card padding (`space-lg` for core accounts, `space-md` for sub-modules).

## Elevation & Depth

Visual hierarchy is generated through translucent glass strata, optical backdrop filters, and luminescent back-glows:

- **Level 0 (Canvas Base):** Solid `#080A0F` canvas void.
- **Level 1 (Subsurface Plates):** Frosted glass composites: `rgba(18, 22, 34, 0.65)` layered with `backdrop-filter: blur(24px) saturate(180%)`. Border rendered as a 1px composite outline with gradient falloff—subtly shifting from `rgba(212, 249, 51, 0.24)` at the top edge to `rgba(255, 255, 255, 0.05)` at the bottom edge.
- **Level 2 (Tactile Floating Controls & Keypad Buttons):** Opaque dark slate (`#131722`) floating slightly forward. Receives a subtle inset top reflection (`box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.12)`) and a diffused ground shadow (`0 8px 24px -4px rgba(0, 0, 0, 0.5)`).
- **Level 3 (Hyper-Active & Focus Aura):** Used exclusively for primary interactive states and electric CTAs. Produces an ambient radial bloom: `0 0 24px rgba(212, 249, 51, 0.35), 0 4px 12px rgba(0, 0, 0, 0.4)`. No muddy drop shadows are allowed; depth is defined by luminance contrast.

## Shapes

The geometric architecture uses `roundedness: 2` (16px / `1rem` on base containers, scaling up to `1.5rem` for prominent master cards) blended with strict pill morphology for interactive micro-modules.

- **Primary Cards & Modals:** Standardized on 24px (`rounded-xl` / `1.5rem`) for a tailored, handheld device feel.
- **Keypad Nodes:** Full circular geometry (`rounded-full`) providing centered radial touch feedback.
- **Status Tags & Pill Badges:** Fully radiused pill shapes (`9999px`) to create distinction between analytical badges and square information cells.
- **Action Triggers:** Full-width rounded pills (16px to 24px) to ensure soft, finger-friendly hit states across mobile screens.

## Components

### Action Triggers (Buttons)
- **Primary CTA:** High-voltage Electric Lime (`#D4F933`) fill paired with deep ink-black text (`#080A0F`) in `Space Grotesk Bold`. Features subtle neon bloom glow on hover/active states, 52px height, fully rounded or 16px radius, and an animated icon vector translation on tap.
- **Tactile Keypad Buttons:** Circular 72px buttons crafted in dark slate (`#131722`) with an inset perimeter line. Active state triggers a subtle scale compression (0.95x) and momentary inner lime radiance.
- **Ghost & Secondary Buttons:** Frosted obsidian pill with 1px border (`rgba(255, 255, 255, 0.12)`), white typography, and hover highlight shifting border hue to `rgba(212, 249, 51, 0.4)`.

### Financial Cards & Modals
- **Master Balance Card:** Frosted dark-slate background with 24px radius, top luminous gradient edge, and layered layout. The balance typography (`Space Grotesk Display`) commands visual dominance, flanked by mono account tags and the primary transfer button tucked into the module floor.
- **Transaction Item Tiles:** Horizontal list row encased in a transparent container with hover/active surface highlight (`rgba(255, 255, 255, 0.03)`). Left side displays circular merchant initial avatar with hairline border; center houses title and metadata; right column features monospaced value (`+#120.00` in Lime or `-#38.90` in crisp White/Subtle Gray).

### Badges & Pill Chips
- **Status Pill (`Completed`, `Pending`):** Micro pill with muted status background (`rgba(212, 249, 51, 0.12)`) encasing neon text (`#D4F933`) and an optional 4px pulsing status bead.
- **Card Identifier:** Monospaced pill badge (`rgba(255, 255, 255, 0.06)`) displaying masked credentials with dot-matrix styling.

### Input Controls & PIN Indicator
- **PIN Verification Dots:** Four horizontally aligned hollow rings (`rgba(255, 255, 255, 0.2)`). Upon digit entry, the ring fills with glowing `#D4F933` backed by a luminous micro-shadow glow.
- **Form Input Fields:** Deep obsidian inset fields with 1px base borders, transitioning to an electric lime glow on active keyboard focus. Monospaced helper tags align to upper edges.
